# Windows 11 Basic Cleanup Panel

[🔗 Visit Repo](https://github.com/x4dam/x4dam.github.io/)

A safe, lightweight, and comment-free script to clear system caches, temporary files, and optimize storage on Windows 11.

## How to Run It
Right-click your **Start Menu**, open **PowerShell (Admin)** or **Terminal (Admin)**, and run the following command:

```powershell
irm "x4dam.github.io/main" | iex
```
